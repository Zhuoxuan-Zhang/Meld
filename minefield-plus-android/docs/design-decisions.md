## Clarifications needed to implement the draft

- A long press always toggles a flag. The draft ambiguously assigned both flagging and annotation to long press. Reveal, Flag and Pencil input modes resolve this; Pencil mode opens a 1–8 picker. The larger selected-cell controls independently expose all three operations. Clearing a mark is explicit. A mark is a player annotation, never solver output.
- One undo slot captures the full board before the latest reveal or flag, including flood changes, annotations and timer. Using undo consumes it. A changed pencil mark clears an older slot so undo cannot silently erase a later annotation. Changing input mode preserves the slot. There is no redo.
- Undo is available after a win/loss. Outcomes use a unique game ID, are stored atomically with the board, and are removed when that terminal move is undone. Finishing again adds one result. Statistics count completed games, with wins, integer win rate and best winning duration. Abandoning an unfinished board does not record a loss.
- At most ten flags are allowed; flags block reveal and flood expansion. Flagging clears a mark, and undo restores it. Winning requires revealing all 71 non-mine cells, regardless of flags. A terminal board shows all mines; underlying cell reveal state remains available for exact undo.
- First reveal plants exactly ten mines using the saved seed while excluding that tapped cell. It does not guarantee a mine-free neighborhood or a no-guess solution. Undoing the first reveal restores the unplanted board; repeating the same first reveal produces the same placement.
- Timing starts on first reveal and pauses while explicitly paused, on other tabs, with app dialogs open, or while the activity is not resumed. Pause hides the board and persists across process death. Closing/reopening an active game does not add time spent away. Undo restores the captured timer. An unsaved failure blocks further board edits and warns before Back exits; Retry saves the in-memory session.
- New Game always asks confirmation. Cancellation preserves the board. The replacement is shown only after its complete save succeeds; failure retains the prior board. Completed statistics and preferences survive replacement. The flag default applies to new games and never changes a resumed board's mode.
- The saved session includes undo, mode, pause, marks, outcomes and preferences. One serialized I/O queue avoids out-of-order writes. Corrupt/unknown-version saves show Retry or an explicit archive-and-start-fresh recovery flow. Failed saves remain in memory with a retry button; no claim of successful persistence is made while an error is visible.

## Visual and interaction checks

Light uses the draft's `#FAFAF7` background, white surface, `#1B1B1B` text, and `#1565C0` accent. Dark uses `#121212`, `#1E1E1E`, `#F2F2F2`, and `#90CAF9`. Flag ink on the light surface is darkened from yellow to `#805600` for contrast (6.46:1), and paired with a flag shape. Cell borders use `#7D8792` in light mode (3.65:1 against white) and `#7B8794` in dark mode (4.55:1 against the surface). Primary/on-primary contrasts are 5.75:1 light and 9.94:1 dark. Text/background contrasts are 16.47:1 light and 16.73:1 dark. Numbers are also exposed in spoken cell descriptions. Hidden mine contents are never included in covered-cell accessibility descriptions.

Cells use 4dp corners and a 2dp gap inside a rounded board. Covered cells retain their border; revealed cells flatten into the board background with no border, so revealed empty regions are visibly different from unopened cells without relying on a subtle tint. On typical phone widths all nine columns fit; narrow windows scroll the board horizontally rather than shrinking below 32dp. Larger selected-cell controls provide 48dp touch targets as an alternative to compact cells. Forms and control rows wrap and the page scrolls at large text sizes. Board numerals stay within cell bounds while larger controls follow the system font size. Save failures bring the recovery banner into view. Back closes dialogs, returns Statistics/Settings to Game, and exits Game when saves are complete. Native screenshots and actual verification results belong in the ignored delivery directory, not in claims about the reference APKs.
