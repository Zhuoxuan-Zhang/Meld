# adaptive — coding profile for the supplied Android template

Preserve the approved base-app composition on phones, and adapt it to available window width and height. Use local constraints/BoxWithConstraints and existing Compose primitives; do not guess orientation from a fixed device width. Size a central tree/canvas from the remaining viewport rather than hardcoded heights that displace primary actions. Keep compact-height layouts scrollable and buttons reachable. Respect text scaling, stable tap targets, touch and keyboard input, and safe areas.

Preserve selected task, unfinished input, navigation, scroll position and durable timer state across rotation and recreation. State restoration must reconnect to the same domain operation, not start a second session. Use the current template's navigation/state architecture. Do not migrate to Navigation 3, MediaQuery, Grid/FlexBox or alpha adaptive APIs, or change the supplied Gradle dependencies merely because upstream examples use them. Multi-pane layouts are optional only where they fit the approved design; do not convert a full-screen tree/photo into a cramped detail pane.

Review actual implementation against the approved screen contract. Hidden required actions, a clipped primary tree/canvas, or an unexplained replacement of the approved base navigation/hierarchy are blocking UI defects. Keep small spacing or decorative refinements as follow-ups rather than inventing new product requirements.

When the approved base journey offers an immediate primary action, keep that action visible on the default compact-phone first screen. Reduce redundant gaps and progressively disclose auxiliary creation/editing forms or use existing settings before shrinking the primary tree/canvas. An action available only after scrolling past secondary forms is a blocking hierarchy regression in that main journey. Retained completion/abandonment feedback must be brought into view and its artwork must reflect the terminal state until acknowledgement, including after restored navigation or scroll position.
